# Jarvis Orb

Create a premium AI assistant app named “Jarvis” with a cinematic, futuristic, dark-mode interface. When the app opens, show a smooth cinematic entrance animation: a deep black background fades in, a glowing white Jarvis logo appears at the center, and an elegant transparent animated blob forms behind it.

The visual style should be inspired by Apple Liquid Glass: translucent surfaces, soft blur, subtle reflections, adaptive highlights, rounded corners, smooth morphing transitions, and a clear separation between the main content and navigation layer. Use Liquid Glass selectively for navigation, toolbars, buttons, menus, and floating controls—not for every screen element. Maintain strong text contrast and accessibility. �

Color And Atmosphere

Primary background: cinematic black, charcoal, and deep graphite.

Main text: white and soft gray.

Accent colors: subtle electric blue, violet, and cyan.

Use gentle gradient lighting behind the Jarvis orb.

Add very soft bloom, shadows, reflections, and glass refraction.

Avoid excessive neon, clutter, or bright colors.

Make the interface feel calm, intelligent, premium, and futuristic.

Main Home Screen

Create a centered animated Jarvis AI orb/blob:

The blob should look transparent, glossy, organic, and atmospheric.

It should slowly move and change shape while idle.

Use fluid morphing, subtle particles, light refraction, and breathing animations.

The blob should react to user interaction and voice input.

When Jarvis is listening, make it gently pulse with a blue glow.

When Jarvis is thinking, show slow rotating light waves.

When Jarvis is speaking, animate the blob according to the voice waveform.

Add the text “Jarvis is ready” below the blob.

Include a smaller status message such as “Ask me anything”.

Chat And Terminal Interface

Add a modern conversation interface below or around the Jarvis orb:

Display user and Jarvis messages in clean, minimal cards.

Use transparent dark panels with subtle blur and thin white borders.

Add a terminal-style mode for technical commands and developer tasks.

Terminal messages should use a monospaced font.

Include syntax highlighting for code.

Add copy, retry, stop-generation, and expand controls.

Allow Jarvis to show progress while completing tasks.

Include a typing indicator with three animated dots or a small glowing waveform.

Input Bar

Place a floating input bar at the bottom of the screen using a translucent glass material:

Add a text input field with the placeholder “Message Jarvis…”.

Add a microphone button for voice commands.

Add a send button that appears when the user types.

Add a plus icon on the left side.

Animate the input bar smoothly when the keyboard opens.

Add a subtle glow when the input field is focused.

Support text input, voice input, file uploads, image uploads, and camera capture.

Plus Menu

When the user taps the plus icon, display a small morphing Liquid Glass menu with:

Add file.

Add photo.

Take a photo.

Upload document.

Share screen.

Create task.

The plus button should smoothly transform into the expanded menu using a fluid morph animation. The menu should close with a reverse morph animation when the user taps outside it. Use clear labels and familiar icons.

Navigation Bar

Create a floating translucent navigation bar with smooth morphing transitions. Include:

Home.

Chats.

Terminal.

Tasks.

Profile or Settings.

The active tab should have a soft adaptive glow and a pill-shaped glass highlight. When the user changes tabs, the highlight should smoothly move and morph instead of abruptly switching. Apple describes Liquid Glass as a dynamic material that can adapt to surrounding content and morph as users move between interface areas. �

Jarvis Status Panel

Add a Jarvis Status option in the navigation or settings area. This panel should display real-time information such as:

Current location, only after the user grants location permission.

Local time and date.

Internet connection status.

Battery level.

Device storage.

Microphone and camera permission status.

Current weather, if weather access is enabled.

AI connection status.

Server or API availability.

Current Jarvis activity, such as idle, listening, thinking, speaking, or offline.

Use clear status indicators:

Green: active or healthy.

Yellow: limited or waiting.

Red: unavailable or error.

Gray: permission not granted or disabled.

Do not claim that Jarvis has access to location, device data, microphone, camera, or system information unless the user explicitly grants the required permission.

Settings Screen

Create a beautiful glass-style settings screen containing:

Jarvis personality.

Voice selection.

Voice speed and tone.

Theme selection.

Dark mode and automatic mode.

Animation intensity.

Blob appearance.

Notification controls.

Privacy and permissions.

Location access.

Microphone access.

Camera access.

File and photo access.

Data and chat history controls.

Clear conversation history.

About Jarvis.

Include an “Reduce Motion” option that disables or reduces blob movement, morphing, parallax, and transition animations for accessibility.

Animations

Use smooth, polished animations throughout the app:

Cinematic app launch.

Organic blob movement.

Liquid glass reflections.

Morphing tab navigation.

Expanding plus menu.

Smooth keyboard transitions.

Button press feedback.

Voice-reactive orb animation.

Loading and thinking states.

Page transitions using fade, scale, blur, and spring motion.

Animations should feel natural and lightweight. Avoid distracting constant motion, excessive blur, or overly long transitions.

Responsive And Technical Requirements

Make the layout responsive for mobile, tablet, and desktop screens.

Use accessible text sizes and sufficient color contrast.

Support light mode as an optional theme, while keeping dark cinematic mode as the default.

Keep the main content readable above the visual effects.

Optimize animations so they do not drain battery or reduce performance.

Use reusable components for the orb, chat messages, terminal, input bar, plus menu, navigation bar, status cards, and settings.

Add realistic loading, offline, permission-denied, and error states.

Use placeholder data for system information until real APIs and permissions are connected.

Do not copy Apple logos, trademarks, or proprietary assets; use an original glass-inspired design.

Overall Experience

The final app should feel like a futuristic personal AI operating system: elegant, cinematic, minimal, intelligent, and responsive. The first impression should be a glowing white Jarvis identity in a dark environment, followed by a calm transparent animated orb, a glass input bar, smooth morphing navigation, terminal capabilities, voice interaction, file and photo attachments, and a real-time Jarvis status panel.
